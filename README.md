## Getting Started

### Prerequisites

* PostgreSQL Client Tools
* Docker
* Docker compose

<!-- USAGE EXAMPLES -->
## Usage

1. Install dependencies using `pip install -r requirements.txt`
2. Run postgresql db using `docker compose up`
3. Make sure you have `libpq` postgresql client library in your path
2. Run the application with `python main.py`
